# Application Help

Les administrateurs peuvent gérer les clients, créer des comptes, consulter les
opérations et suivre les statistiques du tableau de bord.

Les utilisateurs se connectent avec un JWT. Le frontend Angular ajoute le token
dans l'en-tête Authorization pour appeler les routes sécurisées.

Le chatbot aide à comprendre les fonctionnalités, les clients, les comptes, les
opérations et les statistiques simples disponibles pour l'utilisateur connecté.
